## 🚀 Quick Start

### Prerequisites
1. Hacked PS Vita with custom firmware (HENkaku/h-encore²/Trinity)
2. Adrenaline v7.0 or later installed
3. VitaShell for file transfer

### Installation (5 minutes)
1. Download this repository
2. Connect Vita to PC via USB or FTP
3. Copy `WTH/` folder contents to `ux0:/pspemu/PSP/GAME/WAGIC/`
4. Open Adrenaline on Vita
5. Navigate to Game → Memory Stick
6. Launch "Wagic the Homebrew"

**Full instructions**: See `WAGIC_VITA_GUIDE.md`

## ❓ FAQ

**Q: Is this a native Vita VPK?**
A: No, this is the PSP version that runs via Adrenaline emulator. Native Vita porting would require significant development work.

**Q: Will this work on my Vita?**
A: Yes, if your Vita is hacked and has Adrenaline installed.

**Q: Can I play online?**
A: No, Wagic is single-player only (vs AI).

**Q: Are all Magic cards supported?**
A: Most cards work, with some complex interactions simplified or unsupported. Check the included documentation for details.

**Q: Can I add my own cards?**
A: Yes! Wagic supports custom card creation. See the modding documentation.

**Q: Where are save files stored?**
A: In `ux0:/pspemu/PSP/SAVEDATA/WAGIC*/`
